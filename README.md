# Veil Protocol

Открытая спецификация протокола Veil: анонимной публикации сообщений в Telegram-группе через
личных ботов пользователей.

- Спецификация: [`spec/`](spec/00-overview.md)
- Открытые вопросы: [`OPEN_QUESTIONS.md`](OPEN_QUESTIONS.md)
- Публичные ключи сервера: [`keys.json`](keys.json) (подписан `server_sig`). Ключ эмитента клиент закрепляет
  именно отсюда, а не из ответа сервера (spec/03); приёмные ключи сервер отдаёт операцией `keys.get`.
- Как сообщить об уязвимости: [`SECURITY.md`](SECURITY.md)
- Тестовые векторы для независимых реализаций клиента: [`test-vectors/`](test-vectors/)

Эталонный клиент: [veil-client](https://github.com/a58becde/veil-client).
Любой может написать свой клиент на любом языке: протокол открыт полностью, а анонимность
держится на криптографии, а не на секретности кода сервера.

Статус: черновик v1. Сервер реализован и работает с тестовой группой (2026-10-15); эталонный бот пользователя —
[veil-client](https://github.com/a58becde/veil-client).
